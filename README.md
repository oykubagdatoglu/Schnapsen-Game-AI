# Schnapsen Game AI — Strategy Optimisation

AI bots for the Schnapsen card game using Minimax algorithm with Alpha-Beta pruning.

## Overview

Built as part of the Project Intelligent Systems course at Vrije Universiteit Amsterdam. Grade: 56/60.

## Features

- 4 AI bots: AggressiveBot, DefensiveBot, AlphaBetaBot, RandBot
- Minimax algorithm with Alpha-Beta pruning
- Heuristic evaluation functions
- 10,000-game simulations with statistical validation
- Binomial tests and 95% confidence intervals
- 40% reduction in computational overhead through pruning optimisation

## Technologies

- Python
- LaTeX (Springer LLNCS academic format)
- Statistical Analysis (Binomial Test, Confidence Intervals)

## Results

AlphaBetaBot significantly outperformed baseline bots across 10,000 simulations. Pruning reduced computational overhead by 40% compared to standard Minimax.
